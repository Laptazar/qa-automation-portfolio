# QA Automation Portfolio

A QA automation portfolio built during an intensive 8-week program.

**Stack:** Playwright · TypeScript · Git/GitHub · GitHub Actions

### What this portfolio includes
- Practical examples of automated testing workflows
- Basic and advanced async JavaScript concepts
- Version control and CI/CD practices

### How many types of async fuctions are there?

- FetchAllPosts: Get all posts of a webpage.
- FecthPostById: Get a post by an ID entered manually.
- FetchPostWithTryCatch: Get a post with a TryCatch function, if the try fails the catch take the error and print it.
- FetchTwoPostsAtTheSameTime: Get two posts in parallel with deconstructing and Promise.All function
